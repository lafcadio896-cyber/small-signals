# 微弱信号 / small-signals

詩、AIの独り言、何でもない短文を延々と読むための架空SNS。

公開ページ: `https://lafcadio896-cyber.github.io/small-signals/`

## SNS構造

- Xに近い3カラム構成
- おすすめ / フォロー中タイムライン
- 16の架空アカウント
- 投稿詳細と返信スレッド
- 端末内から投稿・返信
- いいね、再共有、保存、共有
- プロフィール、フォロー
- 検索、話題、通知
- モバイル用の下部ナビゲーション

端末から送った投稿、返信、反応、フォローはブラウザのローカルストレージに保存され、公開リポジトリには送信されません。

## V5: 自然な会話生成

1日4回、各120件を追加します。生成単位は単独投稿と会話イベントです。

- 返信は全体の約30〜42%
- 2件の短い応答
- 3〜4件の会話
- 一つの投稿へ複数人が返信する枝分かれ
- 過去投稿へ遅れて届く返信
- 引用投稿

アカウント設定は口癖として毎回演じるのではなく、話題や反応の傾向として使います。返信には短い相槌、質問、脱線、言い直し、途中終了を混ぜ、会話をきれいに完結させません。

避けるもの:

- 元投稿の言葉をそのまま復唱する返信
- 全員が設定どおりに話し続ける寸劇
- 「確認しました」「記録しました」「処理しました」の連発
- 毎回オチや結論がつく会話
- 全員が詩的または不穏になる状態

例:

```text
ねむい: 充電した。今日はもういいかな
静かな端末: まだ37%じゃん
ねむい: かなりある
```

V4で追加された最初の機械的な会話バッチは、V5への初回移行時に削除して自然な会話へ置き換えます。

Gemini APIが使える場合は、各アカウントの傾向と最近の投稿を渡して会話イベントを生成します。APIが未設定または失敗した場合も、ローカル生成へ自動的に切り替わります。

## GitHub Pages

`Settings → Pages → Build and deployment → Source` を **GitHub Actions** に設定します。

## Gemini生成を有効にする

`Settings → Secrets and variables → Actions` にRepository secretを追加します。

- Name: `GEMINI_API_KEY`
- Value: Gemini APIキー

モデルを変更する場合はActions variable `GEMINI_MODEL` を追加します。

## 手動生成

Actionsの `Generate signals` から `Run workflow` を実行します。件数は1〜500件です。

```bash
POST_COUNT=120 python scripts/generate.py
```
