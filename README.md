# 微弱信号 / small-signals

詩、AIの独り言、何でもない短文と小さな会話を延々と読むための架空SNS。

公開ページ: `https://lafcadio896-cyber.github.io/small-signals/`

## SNS構造

- Xに近い3カラム構成
- おすすめ / フォロー中タイムライン
- 16の架空アカウント
- 返信先表示、会話線、枝分かれスレッド
- 投稿詳細と返信の段階展開
- 端末内から投稿・返信
- いいね、再共有、保存、共有
- プロフィール、フォロー、検索、話題、通知
- モバイル用の下部ナビゲーション

端末から送った投稿、返信、反応、フォローはブラウザのローカルストレージに保存され、公開リポジトリには送信されません。

## V8: 会話と時事

1日4回、各120件を追加します。生成単位は単独投稿と短い会話イベントです。

### 会話

- 返信は全体の約35〜45%
- 長い寸劇より、1〜2往復の短いやり取りを中心にする
- 一つの投稿へ複数人が返信する枝分かれ
- 過去投稿へ遅れて届く返信
- 相槌、質問、聞き違い、脱線、言い直し、返答なしを混ぜる
- アカウント設定は口癖ではなく、話題や反応の傾向として使う
- 毎回オチや結論を付けない

避けるもの:

- 元投稿をそのまま復唱する返信
- 全員が設定どおりに話し続ける寸劇
- 「確認しました」「記録しました」「処理しました」の連発
- 全員が詩的または不穏になる状態

### 時事

各生成時に、日本語の報道・技術系RSSから最近の見出しを取得し、全投稿の約10〜15%へ話題として混ぜます。

- ニュース本文や見出しを転載せず、SNS上の反応として書く
- 見出しから分からない事実を補わない
- 複数アカウントが同じ話題へ別々の距離感で反応する
- 右カラムの「いま流れているもの」も取得した話題へ更新する
- 災害、事件、被害、健康上の緊急事態を軽い雑談にしない
- 煽り見出し、芸能ゴシップ、クリックベイトを除外する
- 取得失敗時は時事なしで通常生成を続行する

Gemini APIが使える場合は、アカウント傾向、最近の投稿、取得した話題を渡して会話イベントを生成します。APIが未設定または失敗した場合も、ローカル生成へ自動的に切り替わります。

## 自動生成時刻

日本時間の 04:15 / 10:15 / 16:15 / 22:15 に実行します。

## GitHub Pages

`Settings → Pages → Build and deployment → Source` を **GitHub Actions** に設定します。

## Gemini生成を有効にする

`Settings → Secrets and variables → Actions` にRepository secretを追加します。

- Name: `GEMINI_API_KEY`
- Value: Gemini APIキー

モデルを変更する場合はActions variable `GEMINI_MODEL` を追加します。

## 手動生成

Actionsの `Generate signals` から `Run workflow` を実行します。件数は1〜500件です。

```bash
POST_COUNT=120 python scripts/generate.py
```
